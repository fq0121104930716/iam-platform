## 简介
本项目是一个基于 Spring Authorization Server 的 OIDC（OpenID Connect）认证与授权服务，提供 OAuth 2.0 授权码流程、令牌签发与刷新、JWT 令牌定制与校验、用户与客户端管理、密码策略与账户锁定机制，以及统一异常处理与 Web 页面交互（登录、注册、授权同意页）。系统通过多配置类实现安全过滤链、OIDC 开启、JWK 密钥管理、令牌定制化、授权服务持久化等关键能力。

**更新** 系统现已重构为双安全过滤链架构，支持多种认证方式，包括传统的用户名密码认证、验证码认证和第三方OAuth2认证。新增多租户认证上下文系统，通过 TenantAwareAuthenticationFilter 和 TenantContext 实现租户级别的认证和权限管理，显著增强了系统的灵活性和用户体验。

- 应用入口：启动类

## 核心组件
- **认证授权服务器配置**：启用 OIDC、设置认证入口、配置 JWT 资源服务器、注册客户端仓库、JWK 源与解码器、授权服务器发行者地址
- **默认安全配置**：定义双安全过滤链，支持验证码认证过滤器和OAuth2登录，开放静态资源与登录/注册页面，表单登录与登出
- **验证码认证过滤器**：拦截验证码登录请求，支持短信和邮箱两种认证方式，执行验证码验证并建立认证上下文
- **自定义OAuth2用户服务**：扩展OAuth2用户信息服务，支持钉钉、微信等第三方平台登录，自动创建或关联用户
- **用户详情服务**：从领域模型加载用户信息，映射角色为权限，支持账户禁用与锁定
- **客户端仓库适配器**：将领域侧 OAuth2Client 映射为 Spring Authorization Server 的 RegisteredClient
- **令牌定制器**：在 JWT 中注入额外声明（邮箱、昵称、角色）
- **授权服务 JDBC 配置**：使用 JDBC 持久化授权与授权同意
- **多租户认证过滤器**：识别并注入租户上下文，支持多种租户识别策略，加载用户权限并创建租户感知令牌
- **租户上下文管理**：线程本地存储当前租户信息，包括租户ID、租户账号ID和人员ID
- **租户感知令牌**：扩展标准认证令牌，包含租户特定数据和权限信息
- **租户拦截器**：从请求头提取租户ID，填充租户上下文
- **密码策略服务**：基础密码强度校验
- **全局异常处理器**：统一业务异常、参数校验、鉴权与访问拒绝、通用异常响应
- **Web 控roller**：登录、注册、授权同意页面路由，租户选择页面

## 架构总览
系统以 Spring Authorization Server 为核心，结合双安全过滤链架构，提供 OIDC 发行与 OAuth 2.0 授权流程。认证服务器负责：
- OIDC 协议启用与 OpenID scope 支持
- 授权码、刷新令牌、客户端凭证等授权类型
- 自定义客户端注册与授权同意
- JWT 签发与校验（基于 JWK）
- 多种认证方式：用户名密码、验证码、第三方OAuth2
- 用户认证与权限映射
- 统一异常处理与 Web 页面交互

**更新** 新架构采用双安全过滤链设计，认证授权服务器过滤链优先级为1，默认安全过滤链优先级为2，确保认证服务器功能独立且不受其他过滤器干扰。新增多租户认证上下文系统，通过 TenantAwareAuthenticationFilter 在认证流程中自动识别租户并注入权限上下文。

### 多租户认证过滤器（TenantAwareAuthenticationFilter）
职责与要点：
- 继承 OncePerRequestFilter，确保每个请求只处理一次
- 识别公共端点并跳过处理，避免对登录、注册等页面产生影响
- 检查认证状态，如果用户未认证则跳过处理
- 如果已经是 TenantAwareAuthenticationToken，则直接跳过
- **新增** 支持多种租户识别策略：X-Tenant-Code 头部、tenant 查询参数、子域名提取
- 从认证信息中提取人员ID，查找对应的租户账号
- 加载租户账号权限，创建租户感知认证令牌
- 更新 TenantContext，设置当前人员ID和租户账号ID
- 将租户感知令牌注册到 SecurityContext

**新增** 这是本次更新的核心组件，实现了完整的多租户认证上下文系统。

## 故障排查指南
常见问题与处理：
- 认证失败：捕获认证异常，返回未授权响应
- 权限不足：捕获访问拒绝异常，返回禁止响应
- 参数校验失败：收集字段错误，返回 400
- 业务异常：根据业务异常状态码返回对应错误
- 未预期异常：记录错误日志，返回 500
- **验证码认证失败**：检查验证码服务配置，确认短信/邮箱服务可用性
- **多租户认证失败**：检查租户代码是否正确，确认租户状态为 ACTIVE，验证用户在目标租户中的账号状态，检查权限加载是否正常

**更新** 新增多租户认证相关的故障排查指导。

```mermaid
Handler-->>Client : 401 Unauthorized + 错误信息
else 多租户认证失败
Handler-->>Client : 401 Unauthorized + 租户上下文错误
else 通用异常
Handler-->>Client : 500 Internal Server Error
end
```

## 结论
本系统通过 Spring Authorization Server 提供了完整的 OIDC/OAuth2.0 能力，结合自定义用户详情服务、客户端适配器、令牌定制器与 JDBC 授权服务，实现了可扩展的认证授权方案。**更新后的双安全过滤链架构**显著增强了系统的灵活性，支持多种认证方式包括传统的用户名密码认证、验证码认证和第三方OAuth2认证。新增的多租户认证上下文系统通过 TenantAwareAuthenticationFilter 和 TenantContext 实现了租户级别的认证和权限管理，支持多种租户识别策略和权限注入机制。配合 Web 页面与全局异常处理，满足生产环境对用户体验与可观测性的要求。建议在生产环境中完善密钥轮换、审计日志、速率限制与更严格的密码策略，并确保验证码服务和多租户系统的高可用性。
