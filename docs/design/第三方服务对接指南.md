# 第三方服务对接 IAM Platform 指南

## 1. 概述

本文档说明第三方 Spring Boot/Spring Security 微服务如何与 IAM Platform 集成，实现统一认证和单点登录（SSO）。

### 1.1 架构概览

```
┌──────────────┐     OIDC/OAuth2      ┌──────────────────┐     JWT/Headers     ┌──────────────────┐
│   浏览器用户   │ ◄────────────────► │  IAM Auth Server   │                   │  第三方业务服务    │
│   (Browser)  │    授权码+PKCE       │  (Port 9000)      │                   │  (Resource Server)│
└──────────────┘                      └──────────────────┘                   └──────────────────┘
                                             ▲                                      ▲
                                             │                                      │
                                             │          IAM Admin Server             │
                                             │          (Port 9002)                 │
                                             └──────────────────────────────────────┘
                                                        应用管理API
```

### 1.2 核心协议

- **OAuth 2.0** - 授权框架
- **OpenID Connect 1.0 (OIDC)** - 身份认证层
- **JWT (JSON Web Token)** - 令牌格式，RS256 签名
- **PKCE** - 防止授权码拦截（Proof Key for Code Exchange）
- **SAML 2.0** - 企业级联邦认证（可选）
- **CAS** - 传统单点登录协议（可选）

### 1.3 IAM Platform 服务说明

| 服务 | 端口 | 职责 |
|------|------|------|
| iam-auth-server | 9000 | 认证服务器、OIDC Provider、令牌颁发 |
| iam-admin-server | 9002 | 管理后台、应用注册、用户管理 |
| iam-gateway | 8080 | API 网关、JWT 验证、路由转发 |
| iam-bff-server | 8081 | Backend-for-Frontend、Web 层适配 |

### 3.3 Security 配置类

```java
package com.example.client.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(authorize -> authorize
                .requestMatchers("/public/**", "/css/**", "/js/**", "/error").permitAll()
                .anyRequest().authenticated()
            )
            .oauth2Login(oauth2 -> oauth2
                .loginPage("/login")
                .defaultSuccessUrl("/dashboard", true)
                .userInfoEndpoint(userInfo -> userInfo
                    .userAuthoritiesMapper(userAuthoritiesMapper())
                )
            )
            .logout(logout -> logout
                .logoutSuccessUrl("https://localhost:9000/oauth2/logout?post_logout_redirect_uri=" 
                    + "http://localhost:8080")
            );
        
        return http.build();
    }
    
    @Bean
    public GrantedAuthoritiesMapper userAuthoritiesMapper() {
        return authorities -> {
            // 从 OIDC 映射 authorities
            return authorities;
        };
    }
}
```

### 3.4 获取用户信息

```java
package com.example.client.controller;

import org.springframework.security.core.Authentication;
import org.springframework.security.oauth2.core.user.OAuth2User;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;

import java.util.Map;

@Controller
public class DashboardController {

    @GetMapping("/dashboard")
    public String dashboard(Model model, Authentication authentication) {
        if (authentication.getPrincipal() instanceof OAuth2User oauth2User) {
            Map<String, Object> attributes = oauth2User.getAttributes();
            
            model.addAttribute("sub", oauth2User.getName());
            model.addAttribute("email", attributes.get("email"));
            model.addAttribute("nickname", attributes.get("nickname"));
            model.addAttribute("roles", attributes.get("roles"));
            model.addAttribute("tenant_id", attributes.get("tenant_id"));
        }
        
        return "dashboard";
    }
}
```

## 4. Resource Server 模式（API 保护）

适用于需要验证 JWT 的后端服务，通常位于网关之后。

### 4.1 架构说明

IAM Platform 支持两种 Resource Server 集成模式：

**模式一：通过 Gateway 转发（推荐）**
```
Client → Gateway (JWT验证) → 业务服务 (信任Gateway Headers)
```

Gateway 验证 JWT 后，通过 HTTP Header 传递用户信息：
- `X-User-Id` - 用户 ID
- `X-User-Name` - 用户名
- `X-User-Roles` - 角色列表（逗号分隔）

**模式二：直接验证 JWT**
```
Client → 业务服务 (直接JWT验证)
```

业务服务直接验证 JWT 签名和 claims。

### 4.2 模式一：信任 Gateway Headers

**Maven 依赖：**
```xml
<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-security</artifactId>
    </dependency>
</dependencies>
```

**Security 配置：**
```java
package com.example.api.config;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.util.Arrays;
import java.util.stream.Collectors;

@Configuration
@EnableWebSecurity
public class ApiSecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(authorize -> authorize
                .requestMatchers("/actuator/health", "/error").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .requestMatchers("/api/**").authenticated()
                .anyRequest().authenticated()
            )
            .sessionManagement(session -> session
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
            )
            .csrf(csrf -> csrf.disable())
            .addFilterBefore(gatewayUserContextFilter(), 
                UsernamePasswordAuthenticationFilter.class);
        
        return http.build();
    }
    
    @Bean
    public GatewayUserContextFilter gatewayUserContextFilter() {
        return new GatewayUserContextFilter();
    }
    
    /**
     * 从 Gateway 传递的 Header 中提取用户上下文
     */
    public static class GatewayUserContextFilter extends OncePerRequestFilter {
        
        @Override
        protected void doFilterInternal(HttpServletRequest request, 
                HttpServletResponse response, FilterChain filterChain) 
                throws ServletException, IOException {
            
            String userId = request.getHeader("X-User-Id");
            
            if (userId != null && !userId.isEmpty()) {
                String userName = request.getHeader("X-User-Name");
                String rolesHeader = request.getHeader("X-User-Roles");
                
                var authorities = Arrays.stream(rolesHeader != null ? rolesHeader.split(",") : new String[0])
                    .filter(role -> !role.isEmpty())
                    .map(role -> new SimpleGrantedAuthority("ROLE_" + role))
                    .collect(Collectors.toList());
                
                var authentication = new UsernamePasswordAuthenticationToken(
                    userId, null, authorities);
                
                SecurityContextHolder.getContext().setAuthentication(authentication);
            }
            
            filterChain.doFilter(request, response);
        }
    }
}
```

### 4.3 模式二：直接验证 JWT

**Maven 依赖：**
```xml
<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-oauth2-resource-server</artifactId>
    </dependency>
```

**配置文件：**
```yaml

  security:
    oauth2:
      resourceserver:
        jwt:
          issuer-uri: ${IAM_ISSUER_URI:https://localhost:9000}
          # 或通过 JWK Set URI 手动配置
          # jwk-set-uri: ${IAM_ISSUER_URI:https://localhost:9000}/oauth2/jwks
```

**Security 配置：**
```java
package com.example.api.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationConverter;
import org.springframework.security.oauth2.server.resource.authentication.JwtGrantedAuthoritiesConverter;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
@EnableWebSecurity
public class JwtResourceServerConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .sessionManagement(session -> session
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
            )
            .authorizeHttpRequests(authorize -> authorize
                .requestMatchers("/public/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .requestMatchers("/api/**").authenticated()
                .anyRequest().authenticated()
            )
            .oauth2ResourceServer(oauth2 -> oauth2
                .jwt(jwt -> jwt
                    .jwtAuthenticationConverter(jwtAuthenticationConverter())
                )
            );
        
        return http.build();
    }
    
    @Bean
    public JwtAuthenticationConverter jwtAuthenticationConverter() {
        JwtGrantedAuthoritiesConverter grantedAuthoritiesConverter = 
            new JwtGrantedAuthoritiesConverter();
        
        // 从 JWT 的 "roles" claim 提取权限
        grantedAuthoritiesConverter.setAuthoritiesClaimName("roles");
        grantedAuthoritiesConverter.setAuthorityPrefix("ROLE_");
        
        JwtAuthenticationConverter jwtAuthenticationConverter = 
            new JwtAuthenticationConverter();
        jwtAuthenticationConverter.setJwtGrantedAuthoritiesConverter(
            grantedAuthoritiesConverter);
        
        return jwtAuthenticationConverter;
    }
}
```

**获取 JWT Claims：**
```java
package com.example.api.controller;

import org.springframework.security.core.Authentication;
import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationToken;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.List;
import java.util.Map;

@RestController
@RequestMapping("/api")
public class UserController {

    @GetMapping("/profile")
    public Map<String, Object> getProfile(Authentication authentication) {
        JwtAuthenticationToken jwtAuth = (JwtAuthenticationToken) authentication;
        Jwt jwt = jwtAuth.getToken();
        
        return Map.of(
            "sub", jwt.getSubject(),
            "email", jwt.getClaim("email"),
            "nickname", jwt.getClaim("nickname"),
            "roles", jwt.getClaim("roles"),
            "tenant_id", jwt.getClaim("tenant_id")
        );
    }
}
```

## 5. JWT Token 详解

### 5.1 Token 结构

IAM Platform 颁发的 JWT 包含以下 claims：

**标准 Claims：**
| Claim | 类型 | 说明 | 示例 |
|-------|------|------|------|
| `iss` | String | Issuer (签发者) | `https://localhost:9000` |
| `sub` | String | Subject (用户标识) | `user-uuid-123` |
| `aud` | String | Audience (受众) | `a1b2c3d4e5f6g7h8` |
| `exp` | Number | Expiration Time (过期时间) | `1704067200` |
| `iat` | Number | Issued At (签发时间) | `1704063600` |
| `jti` | String | JWT ID (唯一标识) | `uuid-generated` |

**自定义 Claims：**
| Claim | 类型 | 说明 | 示例 |
|-------|------|------|------|
| `email` | String | 用户邮箱 | `user@example.com` |
| `nickname` | String | 用户昵称 | `张三` |
| `roles` | Array | 角色列表 | `["ADMIN", "USER"]` |
| `permissions` | Array | 权限列表 | `["user:read", "user:write"]` |
| `tenant_id` | Number | 租户 ID | `1` |
| `tenant_code` | String | 租户编码 | `default` |
| `tenant_accounts` | Array | 可用租户账号列表 | 见下方示例 |

**tenant_accounts 示例：**
```json
{
  "tenant_accounts": [
    {
      "tenant_account_id": 101,
      "tenant_id": 1,
      "tenant_code": "default",
      "employee_no": "EMP001"
    },
    {
      "tenant_account_id": 102,
      "tenant_id": 2,
      "tenant_code": "partner",
      "employee_no": "EMP002"
    }
  ]
}
```

### 5.2 Token 生命周期

| Token 类型 | 默认有效期 | 说明 |
|------------|-----------|------|
| Access Token | 1 小时 (3600s) | 用于 API 访问 |
| Refresh Token | 24 小时 (86400s) | 用于刷新 Access Token |
| ID Token | 1 小时 (3600s) | OIDC 身份令牌 |

## 6. 核心接口说明

### 6.1 OIDC/OAuth2 端点

|------|------|------|
| `/.well-known/openid-configuration` | GET | OIDC 发现端点 |
| `/oauth2/authorize` | GET | 授权端点 |

### 6.2 授权端点参数

**请求参数：**
| 参数 | 必填 | 说明 |
|------|------|------|
| `response_type` | 是 | 固定值 `code` |
| `client_id` | 是 | 应用 appId |
| `redirect_uri` | 是 | 回调 URI（必须在注册时配置） |
| `scope` | 是 | 作用域，至少包含 `openid` |
| `state` | 推荐 | CSRF 防护随机字符串 |
| `code_challenge` | 条件 | PKCE 验证码（启用 PKCE 时必填） |
| `code_challenge_method` | 条件 | PKCE 方法，固定值 `S256` |
| `nonce` | 推荐 | 防重放攻击随机字符串 |

## 7. 单点登录（SSO）流程

### 7.1 授权码流程（Authorization Code Flow）

```
1. 用户访问业务服务
   GET http://localhost:8080/dashboard
   
2. 业务服务重定向到 IAM Auth Server
   302 Location: https://localhost:9000/oauth2/authorize
       ?response_type=code
       &client_id=a1b2c3d4e5f6g7h8
       &redirect_uri=http://localhost:8080/login/oauth2/code/iam-platform
       &scope=openid profile email
       &state=random-state-string
       &code_challenge=challenge-string
       &code_challenge_method=S256

3. 用户在 IAM Auth Server 登录
   POST https://localhost:9000/login
   (username, password, method)

4. IAM Auth Server 重定向回业务服务
   302 Location: http://localhost:8080/login/oauth2/code/iam-platform
       ?code=authorization-code
       &state=random-state-string

5. 业务服务用授权码换取令牌
   POST https://localhost:9000/oauth2/token
   (grant_type, code, redirect_uri, code_verifier, client_id, client_secret)

6. IAM Auth Server 返回令牌
   { access_token, refresh_token, id_token, expires_in }

7. 业务服务创建会话，用户可以访问受保护资源
```

### 7.2 单点登出（SLO）

**方式一：前端通道登出（Front-Channel）**
```java
@GetMapping("/logout")
public String logout() {
    return "redirect:https://localhost:9000/oauth2/logout"
        + "?post_logout_redirect_uri=" 
        + UriUtils.encode("http://localhost:8080", StandardCharsets.UTF_8);
}
```

**方式二：后端自动登出**
Spring Security OAuth2 Client 会在用户登出时自动清除本地会话。

## 8. 支持的 Scope 和 Claims

| Scope | 说明 | 返回的 Claims |
|-------|------|---------------|
| `openid` | 必须，启用 OIDC | `sub`, `iss`, `aud`, `exp`, `iat`, `jti` |
| `profile` | 用户基本信息 | `nickname`, `roles`, `tenant_id`, `tenant_code` |
| `email` | 用户邮箱 | `email`, `email_verified` |

## 9. 支持的 Grant Types

| Grant Type | 说明 | 适用场景 |
|------------|------|----------|
| `authorization_code` | 授权码流程 | Web 应用（推荐） |
| `authorization_code` + PKCE | 授权码 + PKCE | SPA、移动应用（推荐） |
| `refresh_token` | 刷新令牌 | 获取新的访问令牌 |
| `client_credentials` | 客户端凭据 | 服务间认证（无用户上下文） |
| `password` | 密码模式 | 遗留系统兼容（不推荐） |

## 10. 安全最佳实践

### 10.1 必须项

1. **启用 PKCE** - 防止授权码拦截攻击
   - 在应用注册时设置 `requirePkce: true`
   - Spring Security 5.6+ 默认启用 PKCE

2. **使用 HTTPS** - 生产环境必须启用 TLS/SSL

3. **State 参数** - 防止 CSRF 攻击（Spring Security 自动处理）

4. **Nonce 验证** - 防止重放攻击（OIDC 推荐）

5. **验证 ID Token** - 验证签名、过期时间、audience

6. **正确存储 Client Secret** - 使用环境变量或密钥管理服务

### 10.2 推荐项

1. **最小权限原则** - 只请求需要的 scope
2. **Token 安全存储** - 避免 XSS 攻击
3. **合理配置会话超时** - 平衡安全性和用户体验
4. **错误处理** - 妥善处理认证失败和令牌过期
5. **定期轮换密钥** - 使用 `/api/v1/applications/{id}/rotate-secret`

### 10.3 JWT 验证

Spring Security Resource Server 自动验证：
- ✅ 签名验证（使用 JWK Set 中的公钥）
- ✅ 过期时间验证
- ✅ Issuer 验证
- ✅ Audience 验证

## 11. 常见问题排查

### 11.1 redirect_uri_mismatch

**错误：** 授权请求被拒绝，提示 redirect_uri 不匹配

**原因：** 请求中的 redirect_uri 与注册时配置的不一致

**解决：**
- 检查 application.yml 中的 `redirect-uri` 配置
- 确保与 Admin Server 注册的 callbackUrls 完全一致（包括协议、域名、端口、路径）

### 11.2 invalid_client

**错误：** 令牌请求被拒绝

**原因：** client_id 或 client_secret 错误

**解决：**
- 检查 `appId` 和 `appSecret` 配置
- 确认 appSecret 未被轮换
- 检查客户端认证方法（当前仅支持 `client_secret_basic`）

### 11.3 invalid_grant - Authorization code already used

**错误：** 授权码已被使用

**原因：** 授权码只能使用一次

**解决：** 重新发起授权流程

### 11.4 invalid_token - JWT 验证失败

**错误：** Token 验证失败

**原因：**
- issuer-uri 配置错误
- JWKS 端点不可访问
- Token 已过期

**解决：**
- 检查 `issuer-uri` 配置与实际 IAM Auth Server 地址一致
- 确认 JWKS 端点可访问：`curl https://localhost:9000/oauth2/jwks`
- 查看 JWT 的 `kid` 头是否与 JWK Set 匹配

### 11.5 始终重定向到首页

**现象：** 登录成功后总是跳转到 `/`，而不是用户最初访问的页面

**解决：** 检查业务服务的 Security 配置，确保：
```java
.defaultSuccessUrl("/dashboard", true)  // true = 总是跳转到此 URL
// 改为
.defaultSuccessUrl("/dashboard", false) // false = 优先跳转到原始请求 URL
```

### 11.6 反复显示授权同意页面

**现象：** 用户每次访问都显示授权同意页面

**原因：**
1. 应用配置 `requireAuthorizationConsent: true`
2. 每次请求的 scope 不同
3. 授权记录被删除

**解决：**
- 如不需要同意页面，在应用注册时设置 `requireAuthorizationConsent: false`
- 确保每次请求的 scope 一致

### 11.7 CORS 问题

如前端与后端分离，需要配置 CORS：

```java
@Configuration
public class CorsConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
            .allowedOrigins("http://frontend:3000")
            .allowedMethods("GET", "POST", "PUT", "DELETE")
            .allowCredentials(true);
    }
}
```
