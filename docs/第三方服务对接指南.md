# 第三方 Spring Security 服务对接 IAM Platform 指南

## 1. 概述

本文档详细说明第三方使用 Spring Security 的微服务如何与本 IAM Platform 认证服务进行对接。通过 OpenID Connect (OIDC) 和 OAuth 2.0 协议，第三方服务可以实现单点登录（SSO）和统一身份认证。

### 1.1 对接架构

```
┌─────────────────┐    授权码流程     ┌──────────────────┐    JWT验证     ┌──────────────────┐
│   浏览器/客户端   │ ◄─────────────► │  IAM Platform Server │ ◄───────────► │ 第三方业务服务    │
│   (Resource     │                 │  (Authorization   │               │ (Resource Server)│
│    Owner)       │                 │   Server)         │               │                  │
└─────────────────┘                 └──────────────────┘               └──────────────────┘
```

### 1.2 核心协议

- **OAuth 2.0**: 授权框架
- **OpenID Connect 1.0**: 基于 OAuth 2.0 的身份层协议
- **JWT (JSON Web Token)**: 令牌格式
- **PKCE**: 防止授权码拦截攻击

### 3.3 Security 配置类

创建 Spring Security 配置类：

```java
package com.example.client.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(authorize -> authorize
                // 公开端点
                .requestMatchers("/public/**", "/error").permitAll()
                // 其他请求需要认证
                .anyRequest().authenticated()
            )
            .oauth2Login(oauth2 -> oauth2
                // 自定义登录页面（可选）
                // .loginPage("/custom-login")
                
                // 登录成功后的默认跳转页面
                .defaultSuccessUrl("/dashboard", true)
                
                // 自定义认证成功处理器（可选）
                // .successHandler(customSuccessHandler)
                
                // 自定义认证失败处理器（可选）
                // .failureHandler(customFailureHandler)
                
                // 用户信息服务（可选）
                .userInfoEndpoint(userInfo -> userInfo
                    // 自定义用户属性映射
                    .userAuthoritiesMapper(userAuthoritiesMapper)
                )
            )
            .oauth2Client(oauth2Client -> oauth2Client
                // 授权码请求解析器（支持PKCE）
                .authorizationCodeGrant(codeGrant -> codeGrant
                    .authorizationRequestResolver(authorizationRequestResolver)
                )
            )
            .logout(logout -> logout
                .logoutSuccessUrl("http://sso-server:9000/oauth2/logout?post_logout_redirect_uri=" 
                    + "http://client-app:8080")
            );
        
        return http.build();
    }
}
```

### 3.4 PKCE 支持配置

如果 SSO 服务器要求 PKCE（推荐），需要配置授权请求解析器：

```java
package com.example.client.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.oauth2.client.registration.ClientRegistrationRepository;
import org.springframework.security.oauth2.client.web.DefaultOAuth2AuthorizationRequestResolver;
import org.springframework.security.oauth2.client.web.OAuth2AuthorizationRequestResolver;
import org.springframework.security.oauth2.core.endpoint.OAuth2AuthorizationRequest;

import jakarta.servlet.http.HttpServletRequest;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.SecureRandom;
import java.util.Base64;
import java.util.HashMap;
import java.util.Map;

@Configuration
public class PkceConfig {

    private final ClientRegistrationRepository clientRegistrationRepository;

    public PkceConfig(ClientRegistrationRepository clientRegistrationRepository) {
        this.clientRegistrationRepository = clientRegistrationRepository;
    }

    @Bean
    public OAuth2AuthorizationRequestResolver authorizationRequestResolver() {
        DefaultOAuth2AuthorizationRequestResolver resolver = 
            new DefaultOAuth2AuthorizationRequestResolver(
                clientRegistrationRepository, 
                "/oauth2/authorization"
            );
        
        resolver.setAuthorizationRequestCustomizer(
            OAuth2AuthorizationRequestCustomizers.withPkce()
        );
        
        return resolver;
    }
}
```

或者在较新的 Spring Security 版本中，PKCE 已默认启用。

### 3.5 自定义用户信息映射

SSO 服务器在 JWT 和 Userinfo 中返回自定义 claims，需要映射到 Spring Security 的 OAuth2User：

```java
package com.example.client.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.oauth2.client.userinfo.OAuth2UserRequest;
import org.springframework.security.oauth2.client.userinfo.OAuth2UserService;
import org.springframework.security.oauth2.core.user.DefaultOAuth2User;
import org.springframework.security.oauth2.core.user.OAuth2User;
import org.springframework.security.oauth2.core.user.OAuth2UserAuthority;

import java.util.*;

@Configuration
public class UserInfoConfig {

    @Bean
    public OAuth2UserService<OAuth2UserRequest, OAuth2User> customOAuth2UserService() {
        return userRequest -> {
            OAuth2User oauth2User = new DefaultOAuth2UserService()
                .loadUser(userRequest);
            
            // 提取自定义 claims
            Map<String, Object> attributes = new HashMap<>(oauth2User.getAttributes());
            
            // roles 来自 JWT claims
            List<String> roles = (List<String>) attributes.get("roles");
            String email = (String) attributes.get("email");
            String nickname = (String) attributes.get("nickname");
            
            // 构建 authorities
            Collection<GrantedAuthority> authorities = new ArrayList<>();
            if (roles != null) {
                for (String role : roles) {
                    authorities.add(new SimpleGrantedAuthority("ROLE_" + role));
                }
            }
            
            return new DefaultOAuth2User(
                authorities,
                attributes,
                "sub" // 主标识符属性
            );
        };
    }
}
```

## 4. 核心接口说明

### 4.1 IAM Platform 服务端接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/.well-known/openid-configuration` | GET | OIDC 发现端点，返回服务器配置 |
| `/oauth2/authorize` | GET | 授权端点，发起授权码流程 |
| `/oauth2/token` | POST | 令牌端点，换取访问令牌 |
| `/userinfo` | GET | 用户信息端点，获取用户详细信息 |
| `/oauth2/jwks` | GET | JWK Set 端点，获取公钥用于 JWT 验证 |
| `/oauth2/logout` | POST | 注销端点，结束 SSO 会话 |
| `/login` | GET/POST | 登录页面 |
| `/oauth2/consent` | GET/POST | 授权同意页面 |

### 4.2 授权端点参数

#### 请求参数
| 参数 | 必填 | 说明 |
|------|------|------|
| `response_type` | 是 | 固定值 `code` |
| `client_id` | 是 | 客户端 ID |
| `redirect_uri` | 是 | 重定向 URI（必须在注册时配置） |
| `scope` | 是 | 请求的作用域，至少包含 `openid` |
| `state` | 推荐 | 防止 CSRF 攻击的随机字符串 |
| `code_challenge` | 条件 | PKCE 验证码（当客户端要求 PKCE 时必填） |
| `code_challenge_method` | 条件 | PKCE 方法，固定值 `S256` |
| `nonce` | 推荐 | 防止重放攻击的随机字符串（OIDC 推荐） |

#### 响应参数
| 参数 | 说明 |
|------|------|
| `code` | 授权码 |
| `state` | 原样返回的 state 参数 |

### 4.3 令牌端点参数

#### 请求参数（application/x-www-form-urlencoded）
| 参数 | 必填 | 说明 |
|------|------|------|
| `grant_type` | 是 | 固定值 `authorization_code` |
| `code` | 是 | 授权码 |
| `redirect_uri` | 是 | 与授权请求相同的 redirect_uri |
| `code_verifier` | 条件 | PKCE 原始验证码（如果使用了 PKCE） |

#### 认证方式
使用 HTTP Basic Auth：
```
Authorization: Base64(client_id:client_secret)
```

#### 响应参数
| 参数 | 说明 |
|------|------|
| `access_token` | 访问令牌（JWT 格式） |
| `token_type` | 令牌类型，固定值 `Bearer` |
| `expires_in` | 过期时间（秒） |
| `refresh_token` | 刷新令牌 |
| `id_token` | ID 令牌（JWT 格式，OIDC 特有） |
| `scope` | 授权的作用域 |

## 5. Resource Server 模式（API 保护）

如果第三方服务需要验证来自其他客户端的 Bearer Token，需要配置为 Resource Server：

### 5.1 配置

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          issuer-uri: http://sso-server:9000
```

### 5.2 Security 配置

```java
package com.example.api.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
@EnableWebSecurity
public class ApiSecurityConfig {

    @Bean
    public SecurityFilterChain apiSecurityFilterChain(HttpSecurity http) throws Exception {
        http
            .sessionManagement(session -> session
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
            )
            .authorizeHttpRequests(authorize -> authorize
                .requestMatchers("/public/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .requestMatchers("/api/**").authenticated()
                .anyRequest().authenticated()
            )
            .oauth2ResourceServer(oauth2 -> oauth2
                .jwt(jwt -> jwt
                    // JWT 验证配置
                    .jwtAuthenticationConverter(grantedAuthoritiesExtractor())
                )
            );
        
        return http.build();
    }
    
    @Bean
    public JwtGrantedAuthoritiesConverter grantedAuthoritiesExtractor() {
        JwtGrantedAuthoritiesConverter converter = new JwtGrantedAuthoritiesConverter();
        // 从 JWT 的 "roles" claim 提取权限
        converter.setAuthoritiesClaimName("roles");
        // 添加 ROLE_ 前缀
        converter.setAuthorityPrefix("ROLE_");
        return converter;
    }
}
```

### 5.3 控制器示例

```java
package com.example.api.controller;

            "roles", tokenAttributes.get("roles")
        );
    }
    
    @GetMapping("/admin")

        return "Admin access granted";
    }
}
```

## 6. 刷新令牌流程

当 Access Token 过期时，使用 Refresh Token 获取新的令牌：

### 6.1 自动刷新（Spring Security 默认支持）

Spring Security OAuth2 Client 会自动处理令牌刷新，无需额外配置。

### 6.2 手动刷新

```java
package com.example.client.service;

import org.springframework.security.oauth2.client.OAuth2AuthorizedClient;
import org.springframework.security.oauth2.client.OAuth2AuthorizedClientService;
import org.springframework.security.oauth2.client.registration.ClientRegistration;
import org.springframework.security.oauth2.core.OAuth2RefreshToken;
import org.springframework.security.oauth2.core.endpoint.OAuth2AccessTokenResponse;
import org.springframework.stereotype.Service;
import org.springframework.web.client.RestTemplate;

import java.util.*;

@Service
public class TokenRefreshService {

    private final ClientRegistration clientRegistration;
    private final RestTemplate restTemplate = new RestTemplate();

    public TokenRefreshService(ClientRegistrationRepository clientRegistrationRepository) {
        this.clientRegistration = clientRegistrationRepository.findByRegistrationId("iam-platform");
    }

    public OAuth2AccessTokenResponse refreshAccessToken(String refreshToken) {
        String tokenEndpoint = clientRegistration.getProviderDetails().getTokenUri();
        
        Map<String, String> params = new HashMap<>();
        params.put("grant_type", "refresh_token");
        params.put("refresh_token", refreshToken);
        params.put("client_id", clientRegistration.getClientId());
        
        // 使用 Basic Auth
        String credentials = clientRegistration.getClientId() + ":" 
            + clientRegistration.getClientSecret();
        String encodedCredentials = Base64.getEncoder()
            .encodeToString(credentials.getBytes());
        
        HttpHeaders headers = new HttpHeaders();
        headers.set("Authorization", "Basic " + encodedCredentials);
        headers.setContentType(MediaType.APPLICATION_FORM_URLENCODED);
        
        HttpEntity<String> request = new HttpEntity<>(buildFormData(params), headers);
        
        ResponseEntity<OAuth2AccessTokenResponse> response = restTemplate.postForEntity(
            tokenEndpoint, 
            request, 
            OAuth2AccessTokenResponse.class
        );
        
        return response.getBody();
    }
    
    private String buildFormData(Map<String, String> params) {
        return params.entrySet().stream()
            .map(e -> e.getKey() + "=" + e.getValue())
            .collect(Collectors.joining("&"));
    }
}
```

## 8. 安全最佳实践

### 8.1 必须项

1. **启用 PKCE**: 防止授权码拦截攻击
   ```yaml
   spring:
     security:
       oauth2:
         client:
           registration:
             iam-platform:
               # Spring Security 5.6+ 默认启用 PKCE
   ```

2. **使用 HTTPS**: 生产环境必须使用 HTTPS

3. **验证 state 参数**: 防止 CSRF 攻击（Spring Security 自动处理）

4. **验证 nonce**: 防止重放攻击（OIDC 推荐）

5. **验证 ID Token**: 验证签名、过期时间、audience 等

6. **正确配置授权同意**:
   - 首次接入时设置 `requireAuthorizationConsent: true`
   - 让用户明确知晓授予的权限范围
   - 用户拒绝授权时应优雅处理

### 8.2 推荐项

1. **最小权限原则**: 只请求需要的 scope
   ```yaml
   scope:
     - openid  # 必须
     - profile # 按需
     - email   # 按需
   ```

2. **令牌存储**: 安全存储 Refresh Token，避免 XSS 攻击

3. **会话超时**: 合理配置会话超时时间

4. **错误处理**: 妥善处理认证失败和令牌过期

5. **JWT 验证**: Spring Security Resource Server 自动验证 JWT
   - 签名验证（使用 JWK Set 中的公钥）
   - 过期时间验证
   - Issuer 验证
   - Audience 验证

## 9. 常见问题排查

### 9.1 重定向 URI 不匹配

**错误**: `redirect_uri_mismatch`

**原因**: 请求中的 redirect_uri 与注册时配置的不一致

**解决**: 
- 检查配置文件中的 redirect-uri
- 确保与 SSO 服务器注册的 URI 完全一致（包括协议、域名、端口、路径）

### 9.2 客户端认证失败

**错误**: `invalid_client`

**原因**: client_id 或 client_secret 错误

**解决**:
- 检查凭据配置
- 确认 client_secret 未过期或被轮换
- 检查客户端认证方法（client_secret_basic 或 client_secret_post）

### 9.3 授权码已使用

**错误**: `invalid_grant` - Authorization code already used

**原因**: 授权码只能使用一次

**解决**: 重新发起授权流程

### 9.4 JWT 验证失败

**错误**: `invalid_token` 或签名验证失败

**原因**: 
- JWK Set URI 配置错误
- SSO 服务器重启后密钥变化（KeyID 不一致）

**解决**:
- 检查 issuer-uri 配置
- 确认 SSO 服务器的 JWK 端点可访问
- 查看 JWT 的 `kid` 头是否与 JWK Set 匹配

### 9.5 CORS 问题

如果前端应用与后端分离，需要配置 CORS：

```java
@Configuration
public class CorsConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
            .allowedOrigins("http://frontend:3000")
            .allowedMethods("GET", "POST", "PUT", "DELETE")
            .allowCredentials(true);
    }
}
```

### 9.6 始终重定向到首页而非原始请求

**现象**: 登录成功后总是跳转到 `/`，而不是用户最初访问的页面

**原因**: SSO 服务器配置了 `.defaultSuccessUrl("/", true)`

**解决**: 联系 SSO 服务管理员检查 `DefaultSecurityConfig.java`，确保：
```java
.formLogin(form -> form
    .loginPage("/login")
    .defaultSuccessUrl("/", false)  // ✅ 必须是 false
    .permitAll()
)
```

### 9.7 反复显示授权同意页面

**现象**: 用户每次访问都显示授权同意页面

**可能原因**:
1. 客户端配置 `require_authorization_consent = true`
2. 每次请求的 scope 不同（动态 scope）
3. 授权记录被删除或过期

**解决**:
- 联系 SSO 管理员检查客户端配置
- 如果不需要同意页面，可设置 `require_authorization_consent = false`

### 11.2 支持的 Scope

| Scope | 说明 | 返回的 Claims |
|-------|------|---------------|
| `openid` | 必须，启用 OIDC | `sub`, `iss`, `aud`, `exp`, `iat` |
| `profile` | 用户基本信息 | `nickname`, `picture`, `roles` |
| `email` | 用户邮箱 | `email`, `email_verified` |

### 11.3 支持的 Grant Types

| Grant Type | 说明 | 适用场景 |
|------------|------|----------|
| `authorization_code` | 授权码流程 | Web 应用（推荐） |
| `authorization_code` + PKCE | 授权码 + PKCE | 单页应用、移动应用（推荐） |
| `refresh_token` | 刷新令牌 | 获取新的访问令牌 |
| `client_credentials` | 客户端凭据 | 服务间认证（无用户上下文） |

### 11.4 Token 生命周期

| Token 类型 | 默认有效期 | 说明 |
|------------|-----------|------|
| Access Token | 1 小时 (3600s) | 用于 API 访问 |
| Refresh Token | 24 小时 (86400s) | 用于刷新 Access Token |
| ID Token | 1 小时 (3600s) | 用于身份验证 |

### 11.5 客户端认证方法

| 方法 | 说明 | 安全性 |
|------|------|--------|
| `client_secret_basic` | HTTP Basic Auth（推荐） | 高 |
| `client_secret_post` | 请求体中传递 | 中 |
| `none` | Public Client（PKCE） | 高（需 PKCE） |
